# Git / GitHub 정리

Git·GitHub 관련해서 모으는 노트들의 허브. 새 클리핑/메모 추가 시 아래 목록에 링크만 추가.

## 핵심 개념 요약
- **Git**: 로컬에서 파일 변화 이력을 기록하는 버전 관리 시스템
- **GitHub**: Git으로 관리하는 프로젝트를 클라우드에 올려 협업하는 서비스
- **브랜치**: 원본에 영향 없이 독립적으로 작업하는 공간. 체크아웃 = 그 공간으로 이동
- **기본 흐름**: `git add`(변경사항 선택) → `git commit`(메시지 붙여 저장) → `git push`(업로드) → `Pull Request`(병합 요청) → 리뷰 후 머지
- **비개발자 실전 팁**: 명령어 암기보다 Claude Code에게 "새 브랜치 만들어줘", "작업 끝나면 add commit 해줘", "메인으로 PR 해줘" 식으로 프롬프트 지시
